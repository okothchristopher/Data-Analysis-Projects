# Data Analysis Projects

A collection of data analysis and visualization projects built with Power BI, covering HR analytics, sales analysis, public safety, and global health data.

## Projects

### Power BI

| # | Project | Description |
|---|---------|-------------|
| 01 | [HR Data Analysis](Power%20BI%20Projects/01.%20HR%20Data%20Analysis) | Employee attrition, diversity, and performance analysis across 15,000+ records |
| 02 | [Vehicle Sales Analysis](Power%20BI%20Projects/02.%20Vehicle%20Sales%20Analysis) | Sales performance dashboard for vehicle dealership data |
| 03 | [Accidents Analysis in Nairobi](Power%20BI%20Projects/03.%20Accidents%20Analysis%20in%20Nairobi) | Road accident patterns and trends in Nairobi (2018-2024) |
| 04 | [Diwali Sales Analysis](Power%20BI%20Projects/04.%20Divali%20Sales%20Analysis) | Customer demographics and purchasing behavior during Diwali festival sales |
| 05 | [Life Expectancy Around the World](Power%20BI%20Projects/06.%20Life%20Expectancy%20Around%20the%20World) | Global life expectancy trends from 1950 to 2021 with gender and age breakdowns |

## Tools and Technologies

- **Power BI Desktop** -- Dashboard design, DAX measures, data modeling
- **Excel / CSV** -- Data preparation and cleaning
- **GitHub** -- Version control and project documentation
