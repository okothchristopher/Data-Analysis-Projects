# Accidents Analysis in Nairobi

## Objective

Analyze road accident data in Nairobi to uncover patterns in accident frequency, severity, contributing factors, and victim demographics to support road safety insights.

## Data Source

| File | Records | Description |
|------|---------|-------------|
| `Revised_Incidences.csv` | 6,318 | Accident records with date, location (lat/long), contributing factors, vehicle types, and victim counts (injured/killed) |

The data covers incidents from **2018 onwards**, with details on motorist, pedestrian, and cyclist casualties.

## Key Questions

- What are the most common contributing factors to road accidents?
- Which locations in Nairobi have the highest accident concentration?
- How do accident trends change over time (yearly, monthly)?
- What is the breakdown of victims by type (motorist, pedestrian, cyclist)?

## Technologies

- Power BI Desktop
- DAX

## Dashboard

The report visualizes accident hotspots, contributing factors, and casualty breakdowns.
