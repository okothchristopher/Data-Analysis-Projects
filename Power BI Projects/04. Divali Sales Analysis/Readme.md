# Diwali Sales Analysis

## Objective

Analyze customer purchasing behavior during the Diwali festival to identify key demographics, top product categories, and regional sales patterns.

## Data Source

| File | Records | Description |
|------|---------|-------------|
| `diwali_sales_data.csv` | 11,251 | Transaction records with customer demographics (age, gender, marital status), location (state, zone), occupation, product category, and order amounts |

## Key Questions

- Which age group and gender drive the most sales?
- What are the top-performing product categories during Diwali?
- How do sales vary across states and zones (Western, Southern, etc.)?
- Does marital status or occupation influence purchasing patterns?
